# Stock Ops — Dokumentasi & Desain

Repo ini menyimpan **dokumen produk (PRD)**, **mockup/ referensi desain**, dan **screenshot** untuk
aplikasi **Stock Ops** (PWA gudang untuk ERPNext v16).

> 📦 **Kode aplikasi (Frappe app + PWA frontend) ada di repo terpisah:**
> **https://github.com/denzizzy966/stock_ops** (pola HRMS — app di root + `frontend/`).
> Instalasi & penggunaan lengkap ada di README repo tersebut.

## Isi repo ini

```
├── PRD.md                 # Product Requirements Document (spesifikasi lengkap)
├── design-v2/             # Mockup HTML desain v2 (buka design-v2/index.html)
├── desainv2..v6.png       # Referensi desain
└── ss_*.png               # Screenshot aplikasi
```

## Ringkasan aplikasi

PWA mobile-first: Material Request (Transfer/Pembelian), Stock Entry (Masuk/Keluar/Transfer), stok &
pergerakan per gudang, stok menipis + bulk request, stock opname, scan barcode, foto, geolokasi,
offline + auto-sync, push notification, stok per-employee, ID/EN, dark mode, 4 varian tampilan.

Lihat `PRD.md` untuk detail.
